## 验收标准

- workflow YAML 可被解析；P1/P2 失败时仍上传完整 artifact（含 `.run.json`、全部 JSON 报告、候选文件和 summary）。
- artifact index 列出并哈希校验所有报告、manifest、candidate 和 summary；缺必需文件时输出 `status=failed` 索引并使汇总失败。
- 模拟失败能生成 `pending` 候选；候选生成不修改 `ERRORS.md`；`reject`/`defer` 不修改 `ERRORS.md`；只有 `accept` 生成合法 `M-YYYYMMDD-NNN` 条目。
- 重复 fingerprint 能识别已有候选或账本条目并记录 `duplicate_of`。
- P0 门禁通过；中文治理 coverage=1.0、dimension_ratio=1.0。

- workflow 步骤调整可能影响 `harness_eval_regression` 的合同评估器（artifact_failure_visibility_contract 等），需同步数据集与测试。

- 候选目录与 `ERRORS.md` 的重复检测需要同时覆盖，否则会出现双入口。
