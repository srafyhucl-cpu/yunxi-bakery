- [ ] **Step 2: 实现按发布前状态恢复**

在 `deploy_server.sh` 中将服务恢复拆成两个明确分支：

```bash
restore_service_state() {
    if [ "$SERVICE_WAS_ACTIVE" = "yes" ]; then
        systemctl restart "$SERVICE_NAME"
        wait_for_healthy "$ROLLBACK_VERIFY_WAIT"
        return $?
    fi
    systemctl stop "$SERVICE_NAME" 2>/dev/null || true
    echo "SERVICE_RESTORE_STATUS=inactive"
    return 0
}
```

将 `rollback_release()` 中无条件的 `systemctl restart` 替换为 `restore_service_state`，并保证：

- 发布前服务运行时，回滚后必须恢复为运行并执行健康检查；
- 发布前服务停止时，回滚后必须保持停止；
- 服务停止状态不应被错误判定为“回滚失败”；
- 回滚失败仍输出 `ROLLBACK_STATUS=failed`、写告警并退出 `3`；
- 回滚成功仍输出 `ROLLBACK_STATUS=success`。

函数名称或实现方式可以按现有脚本风格调整，但行为必须满足上述合同。
