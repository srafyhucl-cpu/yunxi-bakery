## 环境注意（本项目历史坑）

- `python` 必须指向 `backend/.venv`，否则 pre-commit 会整片报
  `ModuleNotFoundError: No module named 'pydantic'`
- 提交前 `unset PYTHONPATH`，否则注入的 shim 会让 `test_red_line_rules.py`
  的 unlink 全部 fail-closed
- pytest 一律带仓库外 basetemp：`--basetemp=D:/Project/.tmp-<date>/pytest-base`
- 禁止用 `npm run xxx | tail` 判断退出码，管道会吞掉退出码
- push 用 `git -c credential.helper='!gh auth git-credential' push origin main`
