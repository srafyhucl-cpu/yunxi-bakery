## 一、整体布局

### 桌面端（> 900px）
```
┌──────────┬──────────────────────────────────┐
│          │  顶栏: 头像 + 角色名 + 意图标签     │
│  会话    │──────────────────────────────────│
│  列表    │  消息流                            │
│  280px   │  (含空状态 / 日期分隔 / 消息气泡)   │
│          │                                  │
│          │──────────────────────────────────│
│          │  输入区: 😊 + textarea + ✈       │
└──────────┴──────────────────────────────────┘
```

### 移动端（≤ 900px）— 全屏导航模式
```
状态 A: 会话列表（全屏）        状态 B: 聊天详情（全屏）
┌────────────────────┐         ┌────────────────────┐
│ 💬 AI 对话  [＋新建] │         │ ← [头像] 角色名      │
│────────────────────│         │     🎯 意图标签      │
│ [置顶] 难缠的老太太  │         │────────────────────│
│ [普通] 价格敏感型    │ ──点击──→ │                    │
│ [普通] 催单狂人      │ ←──返回── │    消息气泡...      │
│ ...                │         │                    │
│                    │         │────────────────────│
│                    │         │ 😊 [_____] ✈     │
└────────────────────┘         └────────────────────┘
```
- 两页通过 `transform: translateX(±100%)` + `cubic-bezier` 平滑滑入滑出
- 不透明度 0/1 过渡仅用于桌面端正交显示

## 三、组件清单与交互说明

### 3.1 会话列表（左侧栏）

| 元素 | 样式要点 | 交互 |
|------|---------|------|
| 标题 | "💬 AI 对话", 18px, 600 | 静态 |
| 新建按钮 | 绿色渐变, 6px 圆角, 上浮阴影 | 点击 → 打开角色弹窗 |
| 会话项 | 卡片式, 10px 圆角, hover 右移 2px | 点击 → 选中高亮 + 加载示例对话 + 进入聊天 |
| 置顶标记 | `::before` 伪元素 📌 | 纯装饰 |
| 头像 | 46×46px, 4px 圆角, 渐变底色 | 静态 |
| 激活态 | 白底 + 绿色边框 + 绿阴影 | hover 后切换 |

### 3.2 聊天顶栏

| 元素 | 样式 | 动态 |
|------|------|------|
| 返回按钮（mobile only） | 34×34px, 灰底, 10px 圆角 | hover 左移+变绿, 点击返回列表 |
| 头像 | 38×38px, 4px 圆角 | 从角色名取首字 |
| 角色名 | 16px, 600 | 随弹窗/列表选择更新 |
| 意图标签 | `🎯 商品咨询`, 绿底浅字 | 初始 "等待选择" |

### 3.3 消息流

| 元素 | 样式 |
|------|------|
| 日期分隔 | 渐变线 + 白色胶囊文字 "今天" |
| 用户气泡 | 右对齐, 绿色渐变 `#95ec69`, `border-top-right-radius: 4px` |
| AI 气泡 | 左对齐, 白色, `border-top-left-radius: 4px` |
| 头像 | 40×40px, 4px 圆角, 用户蓝渐变 / AI 绿渐变 |
| 入场动画 | `messageIn`: opacity 0→1 + translateY(10→0), 0.3s |
| 时间戳 | 11px, 浅灰 `#9ca3af` |
| 商品卡片 | 240px 宽, hover 上浮 + 绿边框, 价格红色 |
| 打字指示器 | 三圆点, `typingBounce` 动画, 1.4s 循环 |

### 3.4 输入区域

| 元素 | 样式 | 交互 |
|------|------|------|
| 表情按钮 😊 | 36×36px, hover 浅灰底+变绿 | 点击打开/关闭表情面板 |
| 输入框 | 1.5px 边框, 10px 圆角, focus 绿光晕 | Enter 发送, Shift+Enter 换行, 自动撑高 max 120px |
| 发送按钮 ✈ | 44×44px, 绿色渐变, SVG 图标 | 禁用态灰色; hover 上浮+提亮; 有输入才启用 |

### 3.5 表情面板

- 位置: 输入框上方, `position: absolute; bottom: 100%`
- 尺寸: 290px 宽, 12px 圆角, 白色卡片+阴影
- 网格: 8列, 96 个表情(笑脸/花卉/手势/食物/动物/天气)
- 交互: 点击表情→插入光标位置→面板关闭; 点击外部→关闭

### 3.6 角色选择弹窗

- 遮罩: 半透明黑 + `backdrop-filter: blur(4px)`
- 弹窗: 520px 宽, 20px 圆角, 弹性入场动画
- 角色网格: 2列, 6个预设角色卡片
- 卡片: 选中态绿边框+绿底, hover 上浮
- 自定义输入: 聚焦时取消卡片选中
- 按钮: [退出] 关闭 / [开始对话] 确认→更新顶栏→清空消息→进入聊天
- 关闭方式: ESC / 点遮罩 / 点退出

### 3.7 空状态

- 居中显示: 💬 图标(浮动动画) + 标题 + 说明文字
- 按钮: "选择角色开始 ✨" → 打开角色弹窗
- 有消息时自动隐藏, 无消息时显示

### 3.8 回到底部按钮

- 圆形 44px, 白底阴影, 右下角悬浮
- 不在底部时显示, 到底后隐藏
- hover 变绿

## 四、交互流程

### 4.1 新建对话
```
点击「＋ 新建」→ 弹出角色选择弹窗
  ├─ 选择预设角色 → 绿色高亮
  ├─ 或输入自定义角色名 → 取消卡片选中
  └─ 点击「开始对话」→ 关闭弹窗 → 更新顶栏 → 聚焦输入框
```

### 4.2 发送消息
```
输入文字 → 发送按钮由灰变绿
  ├─ 点击 ✈ 或按 Enter → 用户气泡出现(fadeInUp) → 输入框清空
  ├─ 发送按钮变灰(禁用)
  ├─ "正在输入"三圆点出现 → 1.5~2.5s 后
  ├─ AI 回复气泡出现 → 发送按钮恢复
  └─ 自动滚动到底部
```

### 4.3 查看历史会话
```
点击左侧会话项 → 选中高亮 + 更新顶栏 → 模拟加载历史消息
  ├─ 用户消息: 直接显示
  └─ AI 消息: 1.2s 打字延迟后显示
```

### 4.4 移动端导航
```
初始: 列表全屏, 聊天隐藏在右侧
点击会话项 / 开始对话 → 列表 translateX(-100%) 滑出 + 聊天滑入
点击 ← 返回 → 聊天 translateX(100%) 滑出 + 列表滑入
窗口缩放 >900px → 恢复桌面端双栏布局
```

## 六、开发注意事项

1. **渐进替换**: 先改样式（CSS 变量 + class），不改逻辑；再增加新组件
2. **响应式**: 移动端全屏导航模式需替换当前"上下堆叠"方案
3. **性能**: 动画使用 `transform` + `opacity` 确保 GPU 加速
4. **可访问性**: 后续需补充 ARIA 标签和键盘导航
5. **编码规范**: 中文注释、禁止 TODO、使用项目 CSS 变量
6. **表情面板**: 正式开发时使用 PicMo 或 EmojiMart 库替代手动网格
