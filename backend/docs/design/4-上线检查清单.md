## 二、域名部署方案

已有已备案域名 `yunxifood.cn`，可以直接使用子域名或路径：

```text
API 服务（Webhook 接收 + 管理后台）
     ↓
yunxifood.cn 解析到服务器公网 IP
     ↓
通过 Nginx 反代到 FastAPI 服务
```

| 用途 | 地址 | 说明 | |------|------|------| | 有赞 Webhook 回调 |

- 或使用服务器自带面板的一键 SSL 配置
- Nginx 反向代理 + HTTPS 终结，后端走内部 HTTP 到 FastAPI

## 五、数据安全与合规

| 风险点 | 说明 | 应对措施 | |--------|------|---------| | **客户聊天记录存储** | SQLite 存了对话历史 | 服务器做好安全配置、防火墙、非
root 运行 | | **数据传输** | DeepSeek API 传输对话内容 | HTTPS 传输，不走明文 | | **有赞数据** | 查询订单信息 | 有赞 API 本身 HTTPS |
| **企微数据** | 收发消息 | 企微 API 强制 HTTPS |

**隐私政策建议：** 在小程序/企微的隐私条款里加一句：

> "本服务使用 AI 技术辅助客服回复，对话内容仅用于提升服务质量，不会用于其他目的。"

## 九、部署架构

```text
用户请求 (HTTPS)
    ↓
yunxifood.cn:443
    ↓
Nginx（反向代理）
├─ 静态文件 /admin/static
├─ SSL 证书终结
└─ 转发到 localhost:7001
    ↓
FastAPI (Uvicorn)
├─ /api/v1/webhook/youzan  ← 有赞回调
├─ /admin/*                 ← 管理后台
├─ /health                  ← 健康检查
└─ SQLite (data/bot.db)
```
