## 二、4 个渠道的自动化分析

### ① 小程序（有赞）— 自动化程度最高 ✅

最成熟，最优先。有赞有完整 API，小程序本身就是数字化入口。

| 场景 | 实现方式 | 可行性 | | :--- | :--- | :--- | | AI 售前咨询 | AI 自动回答产品/价格/营业时间 | ✅ | | AI 查订单 | AI 调有赞 API
查物流状态 | ✅ | | AI 售后引导 | 退换货流程引导、退款查询 | ✅ | | 转人工 | 复杂问题无缝转接真人客服 | ✅ |

> **投入产出比最高**：小程序已有、有赞 API 可用、原生后台 RAG 对齐 328 条活跃知识已全面部署上线。

### ② 微信群接龙 — 高自动化潜力 ✅

群内固定格式接龙（如："1. 张三 提拉米苏 x2 周六取"），AI 可自动识别和汇总。

| 场景 | 实现方式 | 可行性 | |------|---------|--------| | 接龙自动汇总 | AI 识别接龙内容，提取结构化订单 | ✅ 固定格式可行 | | 自动确认 |
AI @参与者 确认订单信息 | ✅ | | 接龙到期提醒 | 提醒未参与的客户 | ✅ |

> **前提**：群需要迁移到企业微信，才能用企微 API 监听群消息

### ③ 微信 1 对 1 — 中等自动化 ⚠️

目前是个人微信，没有官方 API 可用，**无法直接自动化**。

**计划**：将客户逐步迁移至企业微信，迁移后可实现：

| 层面 | 自动化方案 | |------|-----------| | 售前咨询（问价格、营业时间等） | AI 以员工身份自动回复 | | 下单处理（"6寸草莓蛋糕下午送到"） | AI
提取订单信息 → 发给客户确认 → 自动录入 | | 情感维护、砍价、投诉 | 转人工处理 |

**迁移策略**：新客户直接加企微，老客户逐步引导，新旧并行过渡。

### ④ 线下到店 — 暂缓 ⚠️

需要 POS 系统配合，与硬件相关，现阶段不纳入 AI 客服范围。

## 四、分阶段路线图

### 第一阶段：小程序 AI 客服（早期路线）

**目标**：替换扣子，在小程序内实现 AI 智能客服

- AI 自动回复产品咨询、门店信息
- AI 查询订单状态、物流进度
- 复杂问题转人工客服
- **不影响现有下单流程**，AI 只做咨询和查询

### 第二阶段：企业微信接入（早期路线）

**目标**：企微 1 对 1 和群接龙接入 AI

前置条件：

- 注册企业微信 → 企业认证（300 元/年）
- 新客户加企微，老客户逐步引导

功能：

- 1 对 1 AI 自动回复（以员工身份）
- 群接龙自动识别与汇总
- 订单统一展示

### 第三阶段：统一订单管理（远期设想）

**目标**：所有渠道订单统一管理

- 订单看板（小程序 + 接龙 + 企微 + 线下）
- 生产单自动生成
- 配送调度

## 五、关于人工介入的设计

### AI 能处理的（不需要人）

- 产品咨询："提拉米苏多少钱？"
- 门店信息："几点开门？"
- 订单查询："我的蛋糕到哪了"
- 常见问题："保质期多久？"

### 需要转人工的

| 情况 | 处理方式 | |------|---------| | 用户主动要求转人工 | AI 识别 → 创建转人工工单 → 通知客服 | | 用户情绪激动/投诉 | AI 识别 → 转人工 |
| AI 连续答不上来 | 自动转人工 | | 要求打折/复杂定制 | 转人工 | | 退款/售后纠纷 | 转人工 |

### 人工介入形式

| 渠道 | 客服怎么回复 | 工具 | |------|-------------|------| | 小程序客服 | 在管理后台网页打字回复 | 浏览器 | | 企微 1 对 1 |
**在企微客户端直接回复**（AI 自动让路） | 企微客户端 | | 企微群 | 群里直接回复 | 企微客户端 |
